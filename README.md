# Neon Brick Breaker

Colorful classic-inspired arcade game in plain HTML/CSS/JS with local HD SVG assets.

## Run

Open `index.html` in a browser.

## Deploy

Push to `main` to deploy automatically via GitHub Pages workflow.

## Controls

- `ArrowLeft` / `ArrowRight` (or `A` / `D`): move paddle
- Mouse / touch drag: move paddle
- `P`: pause / resume

## Features

- 3 handcrafted levels with layered brick durability
- Combo scoring and persistent local best score
- Power-ups: `Expand`, `Slow`, and `Multi-Ball`
- Particle FX and lightweight synth-style game audio
